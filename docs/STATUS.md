# الحالة الفعلية (صادقة) — الإصدار 0.4.0
## مكتوب (لم يُترجم ولم يُشغَّل في Unity بعد)
**النواة (بدون Unity):** الزمن والفصول، الحيوانات الستة، التكاثر والحضانة، العلف والماء (مع احتياج موسمي)، النفوق الاحتمالي، أحداث بيئية اختيارية، تنبيهات، سجل محاسبي مانع للتكرار، أسعار قابلة للتعديل، أنواع المزارع، التقارير (ربح تشغيلي منفصل عن التدفق النقدي)، تصدير CSV، سيناريوهات متفائل/أساسي/متشائم بنطاقات (أدنى/وسيط/أعلى)، الحفظ الآمن مع ترحيل v1→v2، النصوص عربي/إنجليزي، مشكّل الحروف العربية.
**طبقة Unity:** شاشة بداية (اختيار نوع المزرعة)، المزرعة (سرعات/إيقاف/شراء/بيض/حفظ)، السوق (شراء أزواج، بيع بالغ، تعديل الأسعار)، الميزانية (قيم، تدفق نقدي، ربح تشغيلي، مخزون وأيام كفاية، توزيع الحيوانات، رسم الرصيد)، التقارير (يوم/شهر/سنة، ولادات/فقس/نفوق مع المقام والفترة، رسم وارد/صادر، نسخ CSV للحافظة، تشغيل السيناريوهات)، المزيد (لغة، جودة، تقدم الغياب وحده الأقصى، أحداث عشوائية، عملة، مساعدة، خصوصية، مزرعة جديدة)، مشهد ثلاثي الأبعاد بمجسمات بسيطة وكاميرا لمس.
**التزاوج:** زر لكل نوع حامل (أرانب/أغنام/ماعز/أبقار) في السوق يختار أنثى جاهزة وذكرًا سليمًا ويعرض سبب الفشل.
**اختبارات:** 39 اختبار NUnit (35 منها تعمل في GitHub Actions بدون Unity، والأربعة الباقية داخل Unity فقط).
**CI:** core-tests (بدون ترخيص) وunity وunity-activation (يحتاجان ترخيص Unity) — انظر docs/CI.md.
## تحقق جزئي
- جدول الحروف العربية تم التحقق منه آليًا مقابل Unicode، ومنطق المشكّل وُجرِّب بنسخة بايثون (وليس بـ C#).
## غير منفَّذ
- Firebase (تسجيل، مزامنة، حذف حساب) وStart.io (الأزرار تقول "غير مفعلة" بصدق).
- أصول ونماذج حيوانات حقيقية وأنيميشن حقيقي، تجنب التصادم، URP asset.
- بيانات الأنواع خارجية (JSON/ScriptableObject)، مصادر علمية موثقة للقيم (كلها افتراضية).
- البيض عدّاد واحد لكل المزرعة (غير مفصول حسب النوع) والتفريخ للدجاج فقط.
- الحيوانات أفراد فقط (لا مجموعات/دفعات).
- حدود التصدير: النسخ للحافظة فقط (لا مشاركة ملف أصلية).
- إيراد اللحوم والحليب: فئات موجودة في المحاسبة دون آلية إنتاج/بيع بعد.
## مخاطر معروفة (تحتاج جهازًا)
- الخط العربي وأشكال العرض (Presentation Forms-B) قد تظهر مربعات حسب الهاتف.
- الإدخال يستخدم Input القديم: Active Input Handling = Both.
- الأداء 30 إطارًا لم يُقَس. حساب السيناريوهات يعمل تدريجيًا (تشغيل واحد لكل إطار).
- الرسم البياني بسيط (أعمدة uGUI).
## لم يُختبر
- لا Unity ولا dotnet في بيئتي: لم يُترجم أي كود ولم تُشغَّل أي اختبارات هنا. شغّل workflow باسم core-tests من تبويب Actions ليتحقق من ترجمة النواة وتشغيل 35 اختبارًا، وأرسل لي أي خطأ.
- ملفات workflow لم تُجرَّب على GitHub (تحقق من صحة YAML فقط). إصدار Unity وصورة Docker وخطوات الترخيص تحتاج مراجعة من المصدر الرسمي.
