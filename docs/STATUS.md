# الحالة الفعلية (صادقة) — الإصدار 0.2.0
## مكتوب (لم يُترجم ولم يُشغَّل في Unity بعد)
- **النواة (Assets/Scripts/Core):** الزمن، الفصول، الحيوانات، التكاثر، الحضانة، العلف/الماء، النفوق الاحتمالي، السجل المحاسبي المانع للتكرار، الحفظ الآمن (tmp + .bak + ترحيل إصدارات)، النصوص عربي/إنجليزي، مشكّل الحروف العربية.
- **طبقة Unity (Assets/Scripts/Game):** GameController (حلقة اللعب، حفظ تلقائي، تقدم غير متصل، واجهة uGUI تُبنى بالكود: سرعات، إيقاف، شراء علف/ماء/أزواج حيوانات، بيع/تفريخ البيض، تبديل اللغة، سجل أحداث)، FarmView (أرض، سياج، حظيرة، معلف، مشرب، عش، مخزن، إضاءة يوم/ليل، ألوان الفصول، بيض)، AnimalAgent (مشي/أكل/شرب/راحة)، CameraRig (لمس: سحب، قرص للتقريب، التفاف).
- **أدوات المحرر:** قائمة My Smart Farm لإنشاء المشهد وضبط Android.
- **اختبارات:** 20 اختبار NUnit (13 محاكاة + 7 حفظ/نص).
## تحقق جزئي
- جدول أشكال الحروف العربية تم التحقق منه آليًا مقابل أسماء Unicode، ومنطق التشكيل وُجرِّب بنسخة بايثون مطابقة (ليس بـ C# نفسه).
## غير منفَّذ
- مشاهد/أصول نهائية، نماذج حيوانات حقيقية، أنيميشن حقيقي، تجنب التصادم، URP asset، جودة منخفضة/متوسطة/عالية.
- شاشات: اختيار نوع المزرعة، السوق، الميزانية، التقارير، الإعدادات، المساعدة؛ رسوم بيانية؛ CSV؛ سيناريوهات اقتصادية؛ أسعار قابلة للتعديل.
- Firebase (SDK والمزامنة وحذف الحساب)، Start.io.
- البيض غير مفصول حسب النوع (عدّاد واحد للمخصب وآخر لغير المخصب)، والتفريخ للدجاج فقط.
- ملفات بيانات خارجية للأنواع (القيم داخل SpeciesCatalog.cs وهي افتراضية غير موثقة).
## مخاطر معروفة (تحتاج اختبار على جهاز)
- الخط: يحتاج خطًا عربيًا في النظام يدعم Arabic Presentation Forms-B، وإلا ستظهر مربعات.
- الإدخال: يستخدم Input القديم؛ فعّل Active Input Handling = Both أو Old.
- Unity لا يشكّل العربية في Text القديم؛ استخدمنا مشكّلًا بسيطًا (بلا تشكيل، بلا التفاف نصي، بلا عكس أقواس).
- لم يُختبر الأداء (هدف 30 إطارًا) على أي جهاز.
## لم يُختبر
